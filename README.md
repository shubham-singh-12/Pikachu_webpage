# Pokémon Gen I Landing Page ⚡

A clean, modern, and fully responsive landing page featuring **Pikachu** from Generation I, built using HTML5 and CSS3. The project showcases fluid typography, modern layout techniques (CSS absolute positioning, custom fonts, CSS clamp), and icon integrations.

---

## 📌 Project Overview

This project is a single-page concept design inspired by Pokémon Generation I. It uses a dynamic split background gradient, custom web typography, responsive sizing functions (`clamp()`), and floating artwork to create an eye-catching user experience across various screen sizes.

---

## ✨ Features

- **Responsive Design**: Uses CSS `clamp()` functions for seamless scaling of headings, body text, and images across modern display sizes.
- **Custom Typography**: Custom `@font-face` integration using the classic **Pokemon Solid** font alongside clean sans-serif typography.
- **Split Gradient Styling**: Elegant background gradient transition dividing left and right landing sections.
- **Icon Integration**: Icons loaded via CDN using **Remix Icon**.
- **Clean Layout**: Zero-margin baseline with proper z-indexing for layered overlapping elements.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic layout structure.
- **CSS3**: Custom font styling, absolute positioning, CSS gradient, `clamp()` fluid sizing.
- **Remix Icon**: Icon library integration for UI elements.

   ```bash

   ```

2. **Navigate into the directory:**
   ```bash
   cd pikachu_webpage
   ```

3. **Open `index.html`** in your browser, or use a live server extension (e.g., Live Server for VS Code).
